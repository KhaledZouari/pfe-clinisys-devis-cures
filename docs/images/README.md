# Illustrations

Aucune capture brute de l'application d'entreprise n'est publiée dans ce dossier. Les fichiers présents sont des reconstitutions anonymisées réalisées à partir de captures du prototype, uniquement pour expliquer le parcours fonctionnel.

## Fichiers publiés

- `patient-search-fictitious.png` — recherche multicritère anonymisée ;
- `cures-calendar-fictitious.png` — calendrier prévisionnel avec dates fictives ;
- `quote-lines-fictitious.png` — lignes et montants de devis fictifs.

Ces reconstitutions ont été produites avec un outil de retouche générative. Elles documentent les concepts fonctionnels et ne doivent pas être interprétées comme une reproduction pixel-perfect du produit de l'entreprise.
