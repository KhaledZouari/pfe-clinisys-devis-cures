## Publication checklist

Every new or updated image must satisfy all of the following requirements:

- [x] Recreated artwork only; no raw application screenshot
- [x] A visible **FICTITIOUS DATA** label
- [x] Fictitious names, identifiers, dates, quantities, and amounts
- [x] No company, customer, employee, or third-party logo
- [x] No private URL, IP address, hostname, or infrastructure detail
- [x] No real patient or health information
- [x] Final privacy and confidentiality review before publication

## Maintenance guidance

- Prefer PNG for interface mock-ups and optimize files before committing them.
- Use descriptive, lowercase, hyphenated filenames.
- Update the table above and the root README whenever an asset is added or replaced.
- Store original confidential references outside this repository and only in an approved location.
